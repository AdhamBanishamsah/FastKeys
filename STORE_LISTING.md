# Chrome Web Store Listing Information

## Name
**FastKeys**

## Short Description (132 characters max)
Text expander and autofill extension with template management, variables, and date formatting

## Full Description

FastKeys is a powerful text expansion and autofill extension that helps you save time by expanding short triggers into full templates while you type.

### Key Features

**Template Management**
• Create and manage text templates with custom triggers
• Rich text editor with formatting options (bold, italic, underline, lists, links)
• HTML support with "View HTML" mode
• Organize templates with tags
• Export and import templates via JSON files

**Smart Text Expansion**
• Type a trigger (e.g., `_vpn`) + Space/Enter/Tab to expand
• Works in standard inputs, textareas, and rich text editors
• Supports complex editors like Kendo Editor and Power Apps
• Automatic expansion as you type

**Variable Support**
• Insert dynamic variables: `{{first_name}}`, `{{last_name}}`, `{{email}}`
• Create custom variables for your needs
• Autofill panel prompts for missing information
• Variables are replaced with your profile data

**Date Formatting**
• Multiple built-in date formats (long, short, ISO, weekday, time, etc.)
• Gregorian and Hijri (Islamic) calendar support
• **Custom date formats**: Create your own date combinations using strftime-style tokens (%Y, %m, %d, %H, %M, etc.)
• 11 language support for date formatting

**Quick Access**
• Popup interface for fast template insertion
• Keyboard shortcut: Ctrl+Shift+M (Cmd+Shift+M on Mac)
• Search templates by trigger or content
• Recent templates quick access

**Privacy & Control**
• All data stored locally in your browser
• No data sent to external servers
• Full export/import functionality
• Complete control over your templates

### Perfect For

• Customer support teams who type repetitive responses
• Developers who need code snippets
• Content writers with standard templates
• Anyone who types the same text frequently

### How It Works

1. **Create Templates**: Set up templates with triggers (e.g., `_vpn`, `_signature`)
2. **Type & Expand**: Type your trigger + Space/Enter/Tab in any text field
3. **Automatic Insertion**: The trigger expands into your full template instantly
4. **Use Variables**: Add `{{first_name}}`, `{{date}}`, etc. for dynamic content

### Privacy

FastKeys respects your privacy:
• All data is stored locally in your browser
• No data is transmitted to external servers
• No tracking or analytics
• You have full control over your data

### Getting Started

1. Install FastKeys
2. Click the extension icon → Options
3. Create your first template with a trigger
4. Start typing your trigger anywhere on the web!
