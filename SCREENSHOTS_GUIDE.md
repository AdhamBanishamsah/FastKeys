# Screenshots and Promotional Images Guide

This guide will help you create the required images for Chrome Web Store listing.

## Required Images

### 1. Small Promotional Tile
- **Size**: 440 x 280 pixels
- **Format**: PNG
- **Purpose**: Small promotional banner shown in Chrome Web Store
- **Content Suggestions**:
  - FastKeys logo/icon
  - Text: "FastKeys - Text Expander"
  - Brief tagline: "Save time with text expansion"

### 2. Large Promotional Tile
- **Size**: 920 x 680 pixels
- **Format**: PNG
- **Purpose**: Large promotional banner
- **Content Suggestions**:
  - FastKeys branding
  - Key features highlighted
  - Visual representation of text expansion concept

### 3. Screenshots (1-5 images)
- **Size**: 1280 x 800 pixels OR 640 x 400 pixels
- **Format**: PNG or JPEG
- **Purpose**: Show extension features
- **Recommended Screenshots**:

#### Screenshot 1: Template Editor (Main Feature)
**What to show:**
- Options page with template editor open
- Rich text editor with formatting toolbar visible
- Trigger input field
- Date and Variables dropdowns visible
- Save/Discard buttons

**How to capture:**
1. Open Chrome → Extensions → FastKeys → Options
2. Click "Create" → "New Template"
3. Enter a trigger (e.g., `_vpn`)
4. Type some sample text in the editor
5. Make sure formatting toolbar is visible
6. Take screenshot of the entire options page

#### Screenshot 2: Template List with Tags
**What to show:**
- List of templates below the editor
- Templates showing trigger pills (e.g., `_vpn`, `_thinkcell`)
- Tags visible on templates
- Search bar visible
- Filter by tag dropdown

**How to capture:**
1. In Options page, scroll down to template list
2. Ensure 2-3 templates are visible
3. Make sure tags are visible on templates
4. Take screenshot

#### Screenshot 3: Popup Interface
**What to show:**
- Extension popup open
- List of templates visible
- Search functionality
- Recent templates section (if applicable)

**How to capture:**
1. Click FastKeys extension icon in Chrome toolbar
2. Popup should show template list
3. Take screenshot of the popup

#### Screenshot 4: Date Format Options (Optional)
**What to show:**
- Options page → Settings tab
- Date dropdown open showing various formats
- Custom date formats section visible (if you have any)

**How to capture:**
1. Go to Options → Settings tab
2. Scroll to Custom Date Formats section
3. Click Date button in template editor to show dropdown
4. Take screenshot

#### Screenshot 5: Text Expansion in Action (Optional)
**What to show:**
- A webpage (e.g., Gmail compose, or a form)
- Text field with trigger typed
- Expanded text visible (or mid-expansion)

**How to capture:**
1. Open a test webpage (Gmail compose, or any form)
2. Type a trigger (e.g., `_vpn`)
3. Press Space
4. Take screenshot showing the expanded text

## Tools for Creating Images

### Free Options:
1. **Screenshot Tools**:
   - Chrome DevTools (F12) → Device Toolbar → Set custom size
   - macOS: Cmd+Shift+4 (select area) or Cmd+Shift+3 (full screen)
   - Windows: Snipping Tool or Win+Shift+S

2. **Image Editing**:
   - **Canva** (free): https://www.canva.com
     - Create promotional tiles with templates
   - **GIMP** (free): https://www.gimp.org
     - Full-featured image editor
   - **Figma** (free): https://www.figma.com
     - Design promotional tiles

3. **Online Tools**:
   - **Remove.bg**: Remove backgrounds
   - **TinyPNG**: Compress images

## Promotional Tile Design Tips

1. **Keep it Simple**: Don't overcrowd with text
2. **Use Brand Colors**: Match your extension's color scheme (purple/blue theme)
3. **Show Value**: Highlight key benefit (time-saving, productivity)
4. **Readable Text**: Use large, clear fonts
5. **Professional Look**: Clean, modern design

## Screenshot Best Practices

1. **Use Real Data**: Show actual templates, not placeholders
2. **Clean Interface**: Hide unnecessary browser UI if possible
3. **Highlight Features**: Use arrows or annotations if needed
4. **Consistent Style**: All screenshots should have similar look
5. **High Quality**: Use high resolution, clear images
