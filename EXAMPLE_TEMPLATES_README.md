# Example Templates for FastKeys

This file contains example templates that demonstrate various features of FastKeys. You can import these templates to get started quickly.

## How to Import

1. Open FastKeys Options page
2. Click **"Create"** → **"Import Templates"**
3. Select the `example-templates.json` file
4. All templates and tags will be imported

## Included Templates

## Features Demonstrated

These templates showcase:

1. **Variables**: `{{first_name}}`, `{{last_name}}`, `{{email}}`
2. **Date Formats**: 
   - `{{date:long}}` - Full date
   - `{{date:short}}` - Short format
   - `{{date:iso}}` - ISO format
   - `{{date:weekday_long}}` - Day and date
   - `{{date:time_only}}` - Time only
   - `{{date:month_year}}` - Month and year
   - `{{date:long_time}}` - Date with time
3. **Rich Text Formatting**: Bold, lists, line breaks
4. **Tags**: Organized by category (email, code, meeting, etc.)

## Customization

After importing, you can:
- Edit any template to match your needs
- Add your own templates
- Modify variables and date formats
- Create custom date formats
- Add more tags

## Tips

- Replace `[placeholder]` text with your actual content
- Customize variables in Settings → Profile Variables
- Create custom date formats in Settings → Custom Date Formats
- Use tags to organize templates by category

Enjoy using FastKeys! 🚀
